## Titulo del proyecto
-AutoGest - Sistema de gestión vehicular

## Descripción
AutoGest es una plataforma web desarrollafa con el objetivo de centralizar y llevar un mejor
control de la flota vehicular, llevando un registro completo y una mejor administracion de
la información.

## Caracteristicas
-Interfaz amigable con el usuario
-Registros de conductores
-Exporta reportes en formato PDF
-Inicio de sesión por seguridad de sistema

## Tecnologias utilizadas
-PHP
-HTML
-CSS
-JavaScript
-MySQL
-XAMPP

## Requisitos
-PHP 8.2 o superior
-Tener XAMPP instalado

## Instalacion
-Clonar el repositorio
-Crear la carpeta que contendra el proyecto en C:/xampp/htdocs/
-Ejecutar en el XAMPP Apache y MySQL
-Ejecutar la siguiente URL en el navegador: http://localhost/AutoGest/index.php
-Cuando te redireccione a la pagina del instalador, crear las credenciales del
administrador

## Uso
-Iniciar sesion en el sistema con las credenciales del administrador
Al iniciar sesión, el usuario observará un menu lateral izquierdo en donde
estan los botones que llevan a todos los modulos

## Configuración
-En el archivo config.php, ajusta el nombre de la database al nombre de tu base
de datos (AutoGest) y deja todo a como está
