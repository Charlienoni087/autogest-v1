# Sistema Autogest
Proyecto de gestión de flota vehicular

## Estructura
- `/assets`: Archivos con hojas de estilos para la interfaz de usuario, imagenes y logos del sistema.
- `/config`: Conexión a base de datos.
- `/controllers`: Lógica de negocio y autenticación.
- `/installer`: Si el sistema es usado por primera vez, se ejecuta este instalador para crear las credenciales del administrador.
- `/models`: Modelos de datos del sistema.
- `/scripts`: Funciones para la interaccion de la pagina y uso de animaciones.
- `/views`: Interfaz de usuario.

## Requisitos
- XAMPP con Apache y MySQL.
- Base de datos importada desde `/database/`.
